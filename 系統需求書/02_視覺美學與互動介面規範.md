# 02. 視覺美學與互動介面規範 (詳細展開版)

本文件旨在定義產品的視覺靈魂，透過現代化的設計語言（Rich Aesthetics）提升用戶黏著度，並在 1000 人 CCU 的高動態環境下維持一致且優質的體感。

---

## 一、 核心設計系統 (Design Tokens)

### 1. 專業級配色方案 (Color Palette)
我們避開單調的純色，改用具備深度的 HSL 色調：
- **Primary (主色)**: `hsl(221, 83%, 53%)` - 電子藍，象徵科技與信任。
- **Success (成功/在線)**: `hsl(142, 71%, 45%)` - 祖母綠。
- **Surface (表面)**: 
  - Light: `hsl(210, 40%, 98%)` (極淺冷灰)
  - Dark: `hsl(222, 47%, 11%)` (深海藍)
- **Gradient (漸層)**: 
  - 對話框背景：`linear-gradient(135deg, #6EE7B7 0%, #3B82F6 100%)`

### 2. 字體系統 (Typography)
- **Primary**: `Outfit`, `Inter` (Sans-serif) - 現代感強且易讀。
- **Scale**:
  - `H1 (標題)`: 32px / 700 weight / Tracking -0.02em
  - `Body (訊息)`: 16px / 400 weight / Line-height 1.5
  - `Caption (時間/備註)`: 12px / 500 weight / Color: Secondary Text

---

## 二、 高階美學細節 (Rich Aesthetics)

### 1. 毛玻璃與層次 (Glassmorphism & Layering)
為了讓介面顯得輕盈且具備深度感：
- **偽裝模式 (Panic Mode)**：
  - **桌機觸發**：雙擊標題列或連續按下 `Esc` 兩次。
  - **行動裝置觸發 (Mobile Adaptation)**：支援「雙指快速下滑 (Two-finger swipe down)」手勢或「手機搖晃 (DeviceMotion Sensor API)」觸發。
  - **切換效果**：介面瞬間切換為假的新聞入口網站或專業文檔頁面，聊天內容進入背景掛起並關閉音效。
- **意圖選擇器 (Intent Picker)**：進入配對前提供四種色彩的情緒卡片，選定後背景會產生對應顏色的流光動效。
- **Header & Sidebar**: 
  - `background: rgba(255, 255, 255, 0.7)`
  - `backdrop-filter: blur(12px) saturate(180%)`
  - `border-bottom: 1px solid rgba(255, 255, 255, 0.3)`
- **Shadows**: 
  - 使用「分層陰影」營造真實感：`box-shadow: 0 4px 6px -1px rgba(0,0,0,0.1), 0 2px 4px -1px rgba(0,0,0,0.06)`

### 2. 動態漸層與微動效
- **配對等待區背景**：使用會緩慢流動的 Mesh Gradient (網格漸層)，營造舒適的等待氛圍。
- **按鈕狀態**：
  - `Hover`: 輕微上浮 `transform: translateY(-2px)` + 陰影加深。
  - `Active`: 縮放回饋 `transform: scale(0.95)`。

## 三、 關鍵組件設計規格

### 1. 聊天訊息氣泡 (Chat Bubbles)
- **本人訊息**：
  - 背景：`Primary Gradient`，文字：純白。
  - 圓角：`20px 20px 4px 20px` (右下角直角，營造發言感)。
- **對方訊息**：
  - 背景：`hsl(210, 40%, 96%)`，文字：`Dark`。
  - 圓角：`20px 20px 20px 4px` (左下角直角)。
- **動效**：訊息出現時採用 `Spring` 物理動畫，從下方 20px 處滑入並帶有透明度變化。

### 2. 配對等待與距離選擇界面 (Matching & Distance Screen)
- **視覺重心**：中心顯示隨機幾何圖形或動態防護波浪，四周環繞三層半透明的雷達擴散圓圈 (Radar Animation)。
- **極簡無身份抬頭 (No-Identity Header UX)**：對話頂部抬頭完全不顯示任何姓名、暱稱、身份標籤或隨機編號（因一對一配對無識別需求，抬頭僅保留極簡距離與狀態資訊）。
- **距離篩選拉條控制器 (Distance Filter Slider)**：
  - **互動拉條設計 (Interactive Slider UX)**：採用流暢的動態拉條 (Range Slider)，上方附有刻度標籤與懸浮預覽氣泡 (Tooltip Badge)，支援使用者拖曳拉條或直接點擊刻度進行切換。
  - **8 階離散距離刻度 (8 Discrete Stops)**：
    `1 km 內` ➔ `5 km 內` ➔ `10 km 內` ➔ `20 km 內` ➔ `50 km 內` ➔ `100 km 內` ➔ `不限距離` ➔ **`🚀 越遠越好`**
  - **動態視覺回饋**：
    - 一般距離刻度：顯示品牌主色（電子藍）軌道與微光氣泡標示極速預估配對人數。
    - 滑至最後一階 `🚀 越遠越好`：拉條軌道轉為紫藍色流光漸層，並呈現微光脈衝，提示「已啟用最遠距離配對（避開生活圈與熟人）」。
  - **手機 / 電腦跨裝置定位提示 (Cross-Platform Location UX)**：
    - **手機端 (Mobile)**：顯示「GPS 高精度定位中...」並觸發瀏覽器原生地理授權。
    - **電腦端 (Desktop)**：無 GPS 時自動調用 IP 地理位置並顯示「已自動根據連線區域預估位置 (電腦降級模式)」，提供使用者手動切換。
- **即時版本時間戳記 UI (Live Build Timestamp Badge)**：
  - 在頁尾底部與設定選單小字標示當前網站版本（如：`v1.3.0 Build 20260730_1240`）。
  - 當系統檢測到新版本時，頁尾顯示淡紫流光脈衝並提示「網站已完成無感自動更新」，使用者**完全無需按下 Ctrl+F5**。
- **單一篩選極簡介面 (Single Distance-Filter Constraint)**：配對頁面**僅提供「距離篩選拉條」**作為唯一過濾操作，徹底拔除任何複雜條件選單，達成本地零卡頓、線上秒配體驗。
- **配對成功參考卡片 (Post-Match Reference Chips)**：配對成功後，系統自動於對話視窗頂部抬頭與對話起點渲染對方選填的參考資料（如：`性別` | `年齡層` | `居住城市` | `偏好話題標籤` | `大略距離`），僅供話題破冰參考，不參與前置過濾。
- **資訊顯示**：
  - 距離資訊：成功配對後，頂部標題顯示「距離約 3.2 km 內」或「遠距離匿名對象 (> 150 km)」（若選取越遠越好模式）。（註：全站尋找配對人數動態計數器為維護極簡 UI 與防窺隱私，使用者前端介面完全隱藏，僅於管理員後台即時儀表板顯示）。

## 四、 互動邏輯與 UX 流程

### 1. 訊息發送體驗
- **雙重狀態標記 (Dual Status Indicators)**：
  - **對方已接收 (P2P Delivered)**：單勾選圖示 (`✓`)，淺灰色。表示 WebRTC Data Channel ACK 已成功收到。
  - **伺服器已存檔 (DB Persisted)**：雙勾選圖示或帶有雲端標記之藍勾 (`✓✓` / `☁✓`)，變為 `Primary Blue` 色。表示非同步 Supabase DB 寫入已完成。
  - **伺服器寫入佇列中 / 失敗**：淡黃色重試圖示或紅色警示號，提醒使用者佇列正排定 1 秒重試。
  - 標記位於訊息氣泡的右下角或下方，字體縮小至 10px。
- **狀態更新機制 (P2P + DB)**：
  - 對方接收狀態依賴底層 WebRTC Data Channel 回傳 ACK 訊號即時渲染。
  - 伺服器存檔狀態依賴 Supabase `INSERT` 回傳成功訊號異步更新。
- **離開頁面 UI 阻擋提示 (Unsynced Data Warning Modal)**：
  - 若使用者欲關閉分頁或點擊離開，且 `retry_queue` 中存在超過 40KB 或包含圖片之未寫入資料時，觸發系統 Warning 彈窗：「尚有圖片或訊息未同步至伺服器，立即離開可能導致資料遺失」，給予使用者補救或等待時間。
- **正在輸入中 (Typing Animation)**：
  - 顯示在訊息列表最下方，對方氣泡樣式。
  - 透過 WebRTC 傳送 `typing: true` 輕量訊號觸發。動效：三個圓點依次進行 `Bounce` 跳動（跳動週期 0.6s）。
- **輸入框自動高度**：隨文字行數增加（上限 5 行），背景帶有微弱的內陰影。

### 2. 斷線與重連通知
- **非侵入式提醒**：當網路不穩時，頂部出現 4px 高度的黃色進度條，而非彈窗遮擋，保持對話流暢性。
- **自動復原**：重連成功後，進度條轉綠並在 2 秒後優雅消失。

## 五、 深色模式 (Dark Mode) 專屬優化

- **背景優化**：不使用純黑 `#000`，而是使用帶有藍色調的極深色 `#0F172A`，減少螢幕拖影 (OLED Smearing)。
- **對比度調整**：訊息文字稍微降低對比度（使用 `Light Gray` 而非 `Pure White`），降低長時間聊天產生的視覺疲勞。

---

## 六、 對話狀態與異常處理 (Chat State & Error Handling)

### 1. 離開對話與通知
- **主動離開**：當任一方點擊「離開」按鈕，系統必須在關閉連線前確實將「離開事件」通知給對方，對方介面必須明確顯示「對方已離開聊天室」，並將輸入框設為不可用狀態。
- **重新整理網頁 (Refresh)**：當使用者在配對或對話中重新整理頁面，系統必須能維持並還原當前的配對狀態與對話歷史。若對方在重新整理期間或之前已經離開，系統在重新載入時必須正確讀取狀態，並還原「對方已離開聊天室」的 UI 提示，不可造成配對對象憑空消失或狀態錯亂。

### 2. 定位提示與對方檔案（2026-08 修訂）

- 「配對距離設定」上方須顯示：「開啟定位，配對更快；位置只用來計算大略距離，不會向對方透露您的具體位置。」
- 配對成功參考卡標題固定顯示「對方檔案」，不得附加「破冰參考」字樣。
- 有可用距離時顯示「距離約 X.X km」；小於 1 km 顯示「距離約 < 1 km」；無法計算時顯示「距離無法估算」。
